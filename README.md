# Local Loop

Local Loop is a single-page, mobile-first everyday-tools hub for schools, communities, and local businesses.

It includes six client-side tools: lost and found, lunch polling, room booking, homework tracking, community issue reporting, and cafe preorder. Data is stored locally in the browser, and the dashboard can export all module data to CSV.

The interface is built with plain HTML, CSS, and vanilla JavaScript. There are no frameworks, build tools, backend services, or external libraries.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any simple static server.

## Files

- `index.html` — semantic page structure and all six modules
- `style.css` — responsive dark/light themes, motion, network background, and mobile styles
- `script.js` — local interactions, localStorage, CSV export, search, theme toggle, and motion behavior
